# زمان‌نگار (ZamanNegar PWA) 🚀
**داشبورد هوشمند برنامه‌ریزی روزانه، ردیاب زمان و نمودار فعالیت گیت‌هاب شمسی**
> ساخته شده توسط **امیرحسین آویژه** | [AiVizheh.ir](https://aivizheh.ir)

## ✨ امکانات کلیدی
- 📅 **تقویم و ساعت زنده شمسی** با ذخیره‌سازی چندساله (۱۴۰۲ تا ۱۴۱۰) در حافظه داخلی دستگاه.
- 📲 **وب‌اپلیکیشن نصبی و ۱۰۰٪ آفلاین (PWA)** قابل نصب روی **اندروید (Android)** و **آیفون (iOS Safari)**.
- 🟩 **نمودار فعالیت ۳۶۵ روزه به سبک گیت‌هاب (GitHub Heatmap)** بر پایه تقویم شمسی.
- 🕒 **مدیریت درجای زمان و تایمر زنده** روی هر تسک + انتخابگر ساعت ۲۴ ساعته فارسی.
- 🎨 **۶ تم مدرن** با فونت فارسی **پیدا (Peyda)**.

## 📲 نحوه نصب روی موبایل (اندروید و iOS) از طریق GitHub Pages
1. فایل‌های `index.html`، `manifest.json`، `sw.js`، `icon-192.png` و `icon-512.png` را در مخزن گیت‌هاب خود قرار دهید و از بخش **Settings > Pages** قابلیت **GitHub Pages** را فعال کنید.
2. **در آیفون (iOS):** لینک سایت را در **Safari** باز کنید، دکمه **Share** و سپس **Add to Home Screen** را بزنید.
3. **در اندروید (Android):** لینک سایت را در **Chrome** باز کنید و دکمه **Install App** را بزنید.
